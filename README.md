## 어려웠던 점 3가지와 해결
1.일단 처음어려움을 느꼈던 부분은 찜개수 부분이였다 수정전에는 찜개수가 클릭시 색이바뀌는게 아닌 이미 색이바뀌어있는 문재가 있었다 코드위치를 바꾸니 해결되었다.
2.2번쨰는 step5부분이 가장 어려웠다 분명 코드를 제대로 작성했다고 생각했자만 클릭자체가 안되었다 저번과 마찬가지로 코드위치를 바꾸니 해결되었다.
3.가장 어려웠던 부분은 opendetail의 닫기 부분이였다 닫기버튼을 눌러도 닫히지 않는 오류가 발생했고 코드위치를 바꾸니 해결되었다.
